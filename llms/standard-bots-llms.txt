# Standard Bots

> Standard Bots builds AI-native industrial robotic arms (the RO1 family: Spark, Core/RO1, Thor, Bolt) designed and assembled in the USA for machine tending, welding, palletizing, pick & place, and inspection. The RO1 exposes a developer platform ("StandardOS") including a Bearer-token REST API served on the robot control box, a realtime protobuf external-control stream, a ROS2 bridge, and an official Python SDK.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public surface (developer page, docs, PyPI SDK, GitHub org) on 2026-07-21. Standard Bots does not publish its own /llms.txt (the docs host is a single-page app).

## API
- [RO1 Robotics REST API reference](https://docs.standardbots.com/docs/rest-api/): Control the robot arm, gripper/end-effector, cameras, routines, teleop, recorder, I/O and recovery over /api/v1 with a per-robot Bearer token.
- [Developer platform (StandardOS)](https://standardbots.com/developers): SDK/API overview; Python and TypeScript SDKs (C++, Rust, Go coming soon).
